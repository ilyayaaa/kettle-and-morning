One short text written to relax its reader: it shows a kettle, light on a floor and the speed of morning instead of telling anyone to calm down.

`main.py` (standard library only) writes the text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
